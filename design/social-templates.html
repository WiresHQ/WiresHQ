  1. Edit the text inside a frame. To change category, change the cat-* class and the icon id (#i-sports, #i-entertainment, #i-celebrity, #i-tech, #i-economy).
  2. Open this file in Chrome (the fonts/ folder must sit next to design/). Open DevTools, turn on the device toolbar, set the device pixel ratio to 1.0.
  3. In the Elements panel, right-click the <div class="frame ..."> you edited and choose Capture node screenshot.
  4. Check the PNG's size: 1200 x 630 for the OG cards, 1080 x 1920 for cover and end card.
